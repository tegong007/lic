### 制证设备初始化

**URI**

/tss/doc-machine/init

**Method**

POST

**描述：**

初始化整台制证设备或者其中某个模块。

**输入参数：**

以JSON对象形式存储：

| 字段   | 类型   | 描述                     |
| ------ | ------ | ------------------------ |
| module | string | 初始化的模块，”m0“：全部 |

**返回值：**

以JSON对象形式存储：

| 字段 | 类型    | 描述                             |
| ---- | ------- | -------------------------------- |
| code | integer | 状态码。 当状态码为0时，执行成功 |
| msg  | string  | 描述信息                         |



### 制证设备工位操作

**URI**

/tss/doc-machine/position-operate

**Method**

POST

**描述：**

对制证设备工位上的证本进行操作。

**输入参数：**

以JSON对象形式存储：

| 字段    | 类型     | 描述                                                         |
| ------- | -------- | ------------------------------------------------------------ |
| operate | JSON数组 | 参考[工位定义](#工位定义)<br/>例如: "operate" : [ {"docIndex" : 0, "position" : "M2-Reader-1"}, {"docIndex" : 0, "position" : "M2-Reader-2"}] |

operate数组成员字段表：

| 字段     | 类型    | 描述                                    |
| -------- | ------- | --------------------------------------- |
| fwDocSn  | integer | 证本SN，由固件确定                      |
| position | string  | 证本所在工位，参考[工位定义](#工位定义) |
| platform | integer | 指定证本所在平台，0：平台1，1：平台2                        |

**返回值：**

以JSON对象形式存储：

| 字段 | 类型    | 描述                             |
| ---- | ------- | -------------------------------- |
| code | integer | 状态码。 当状态码为0时，执行成功 |
| msg  | string  | 描述信息                         |

### 制证设备模块状态查询

**URI**

/tss/doc-machine/module-status

**Method**

POST

**描述：**

查询生产过程中各模块的状态信息。

**输入参数：**

| 字段      | 类型   | 描述                                                         |
| --------- | ------ | ------------------------------------------------------------ |
| moduleUid | string | 模块UID：<br />”m1“：模块1；”m2“：模块2；~~...... ”m7“：模块7。~~ |

**返回值：**

以JSON对象形式存储：

| 字段     | 类型         | 描述                             |
| -------- | ------------ | -------------------------------- |
| code     | integer      | 状态码。 当状态码为0时，执行成功 |
| msg      | string       | 描述信息                         |
| respData | JSON对象数组 | 该模块下的工位状态信息           |

**respData**对象字段表：

| 字段     | 类型 | 描述                    |
| -------- | ---- | ----------------------- |
| uid      | str  | [固件工位](#固件工位)。 |
| code     | int  | 状态码。非0，则出错。   |
| msg      | str  | 描述信息。              |
| mainCode | int  | 固件主状态码。          |
| subCode  | int  | 固件子状态码。          |

POST

| 字段              | 类型     | 描述                                                         |

| machineTotalDoc   | integer  | 总本数                                                       |
| machineHandledDoc | integer  | 已进本数                                                     |

**blankCheck、mainPrint、additionPrint**对象字段表：

| name           | string   | 模块名称               |

| msg            | string   | 状态描述               |
| items          | json数组 | 模块显示项对象         |
| periodDataList | json数组 | 模块证本对象           |

**items**对象字段表：

| 字段      | 类型    | 描述                         |

### 工位状态查询

**URI**

/tss/position-status

**Method**

POST

**描述：**

查询生产设备中各模块工位的状态，发证、良本、废本称为**储存工位**，其他的工位称**生产工位**。

**输入参数：**

| 字段     | 类型    | 描述               |
| -------- | ------- | ------------------ |
| moduleID | integer | 模块ID，见模块字典 |

**moduleID**模块字典：

| 代码 | 模块名           |
| ---- | ---------------- |
| 0    | 整机（全部模块） |
| 1    | 空白本检测模块   |
| 2    | 激光打印模块     |
| 3    | 喷墨打印模块     |
| 4    | 成品收集模块     |

**返回值：**

以JSON对象形式存储：

| 字段     | 类型         | 描述                             |
| -------- | ------------ | -------------------------------- |
| code     | integer      | 状态码。 当状态码为0时，执行成功 |
| msg      | string       | 描述信息                         |
| respData | JSON对象数组 | 模块状态数组                     |

respData对象字段表：

| 字段       | 类型         | 描述               |
| ---------- | ------------ | ------------------ |
| moduleID   | integer      | 模块ID，见模块字典 |
| moduleName | string       | 模块名，见模块字典 |
| items      | json对象数组 | 工位状态数组       |

**items**对象字段表：

| 字段              | 类型     | 描述                                           |
| ----------------- | -------- | ---------------------------------------------- |
| item              | string   | 工位名                                         |
| status            | integer  | 状态，祥见状态字典                             |
| msg               | string   | 状态描述                                       |
| historyNum        | integer  | 历史发本数，可选，发证工位用                   |
| historySuccessNum | integer  | 历史成功（良本）数，可选，良本工位、生产工位用 |
| historyFailNum    | integer  | 历史失败（废本）数，可选，废本工位、生产工位用 |
| currentSuccessNum | integer  | 当前机器启动后的成功数                         |
| currentFailNum    | integer  | 当前机器启动后的失败数                         |
| addition          | json     | 附加信息，根据不同的工位而不同                 |
| deviceList        | json数组 | 设备列表                                       |

**status**状态字典：

| 代码 | 状态描述        |
| ---- | --------------- |
| 0    | standy，待机    |
| 1    | working，工作中 |
| 2    | warning，警告   |
| 3    | error，故障     |

**进本工位**-**addition**字段：

| 字段       | 类型    | 描述                      |
| ---------- | ------- | ------------------------- |
| slotStatus | integer | 0：缺本，1：少本，2：充足 |
| docCount   | integer | 剩余的本数                |

**deviceList**字段：

| 字段        | 类型   | 描述     |
| ----------- | ------ | -------- |
| isEnable    | bool   | 是否启用 |
| name        | string | 名称     |
| uid         | string | uid      |
| deviceIndex | string | 设备编号 |

获取所有已录入的人员指纹信息。

**请求：**

无

**响应：**

| 字段     | 类型         | 描述                  |
| -------- | ------------ | --------------------- |
| code     | int          | 状态码。非0，则出错。 |
| msg      | str          | 描述信息。            |
| respData | json对象数组 | 人员指纹信息          |

**respData**包含的信息如下：

| 字段         | 类型   | 描述                            |
| ------------ | ------ | ------------------------------- |
| account      | string | 账号                            |
| idNumber     | string | 身份证号                        |
| fingerprint1 | string | 指纹1，base64编码               |
| fingerprint2 | string | 指纹2，base64编码，预留，可null |
| fingerprint3 | string | 指纹3，base64编码，预留，可null |

/tss/api-transfer

**Method**

POST

**描述：**

用于转发本系统所有接口，返回被转发接口的结果

**输入参数：**

以JSON对象形式存储：

| 字段     | 类型     | 描述                                                         |
| -------- | -------- | ------------------------------------------------------------ |
| transURI | string   | 被转发接口的URI，例如：/m1/send-doc                          |
| paraIn   | JSON对象 | 被转发接口的输入参数，例如：{}(空)，{"status":"M1-Camera-1"} |

**返回值：**

以JSON对象形式存储：

| 字段     | 类型     | 描述                                                         |
| -------- | -------- | ------------------------------------------------------------ |
| code     | integer  | 状态码。 当状态码为0时，执行成功                             |
| msg      | string   | 描述信息                                                     |
| respData | JSON对象 | 以JSON对象形式承载状态信息，根据被转发接口而定，例如：{"code":0,"msg":"成功"} |
